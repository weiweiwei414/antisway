## 14:20 修正回零方向逻辑

用户指出：以原点为中心，在「原点↔正转限位X1」之间按回零应**反转**回零；在「原点↔反转限位X0」之间应**正转**回零。
原代码是 `HOME_DIR = 0` 单向固定，两侧只有一侧能成功。

改法：
- 常量改为按实测命名的 `HomeTowardsFwd = 0` / `HomeTowardsRev = 1`（手册方向语义与实测相反）。
- 新增 `PickHomeDir()`：
  1) 已顶在 X1 → 朝反转端；2) 已顶在 X0 → 朝正转端；
  3) `homed && pos1 >= 0` → 朝反转端；`pos1 < 0` → 朝正转端；
  4) 位置未知 → 先朝正转端猜。
- 新增 `StartHoming(dir)` / `AbortHoming(msg)`；`PollHoming()` 加了三件事：
  - 连续 200ms 压限位 → 判定该方向找不到原点，`homeAttempt==0` 时换方向重找一次；
  - 前 30 拍（1.5s）不看限位，让它先离开起点；
  - 1200 拍（60s）超时中止。
- 新增 `homed` / `homed2` 标记：未回过零 / 未设零点时，位置标签显示「未回零」而不是 0.00 mm（避免假数据）。
- 连接、复位、回零被打断、回零失败时都会清 `homed`。
- 回零开始时 `lastDir = 0`，避免软件限位保护插手回零过程。

## 14:55 改用控制卡内置硬件限位

用户要求：让控制卡自己判断限位（原来是 50ms 软件轮询，每次停车位置差几十~几百脉冲）。

手册与 DLL 确认的签名（务必按这个写）：
- `GA_SetHardLimP(short axis, short nType, short nCardIndex, short nIOIndex)`，nType: -1 无效 / 0 用零位信号 / 1 用通用输入

- `GA_LmtsOn(short axis, short limitType)`，limitType: 0 正 / 1 负 / -1 两者

极性：手册明确"出厂默认常闭、正常低电平、高电平触发"，用户开关正是常闭 → `SetLmtSnsSingle(1,0,0)` 不取反。
  界面留了【极性取反】复选框兜底。

界面：groupBox3 高度 156→190，新增 chkHardLimit（默认勾选）、chkLmtInv；groupBox4 下移到 y=532；ClientSize 640×684。
lblRaw 改为两行：第一行 GPIO/Home 原始值，第二行卡内限位原始值 + 正/反转端是否触发。

新增方法：`ApplyHardLimits(bool)`、`WarnIfHardLimitWrong()`、两个复选框处理器。
状态字用字面量 `STS_HARD_LIMIT_FWD=0x20` / `STS_HARD_LIMIT_REV=0x40`（没依赖库里的常量名）。

**待现场验证**：硬限位触发后，按反方向能否退出（若卡把两个方向都锁死，需要在反向退出前临时 `GA_LmtsOff` 该侧）。
