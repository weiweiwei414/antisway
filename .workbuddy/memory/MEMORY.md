# antiSway 项目长期笔记

桥式卸船机**防摇实验台**上位机程序（WinForms / C#），基于博派 ETH_NEC_NLM 运动控制卡。

## 硬件清单（用户 2026-10-26 确认）

| 部件 | 型号 / 说明 |
|---|---|
| 运动控制卡 | 博派 ETH_NEC_NLM，2 轴版本，网口通讯（PC 192.168.0.200 ↔ 卡 192.168.0.1:60000） |
| 轴1 机械 | **直线模组**（导程待确认） |
| 轴1 电机 | **57 闭环步进电机**（带尾轴编码器，1.8°） |
| 轴1 驱动器 | **HB808C** 闭环步进驱动器（**编码器接在驱动器上，不接卡**） |
| 轴2 电机 | **42 步进电机** |
| 轴2 驱动器 | **TB6600**（细分/电流拨码待确认） |
| 轴2 反馈 | 无编码器，**开环** |

**轴1 闭环 = 驱动器内部闭环**：编码器进 HB808C，驱动器自己纠偏，控制卡只发脉冲、看不到编码器。
因此 `GA_GetAxisEncPos` 读不到值是正常的（界面显示"编码 0"不是 bug）。
副作用：驱动器 ALM 报警卡不知道，除非把 ALM 接到空闲 DI 上监控。
| 电源 | 开关电源（电压待确认） |
| 视觉 | **Intel RealSense D415 深度相机** |

## 接线（实测确认）

- 轴1 两端各一个限位，接通用输入 **X0 / X1**，都是**常闭**光电开关
- 轴1 原点接 **Home1**，**常开**（手册零位编号 Home1~Home8 对应 IO 索引 0~7）
- 实测：按【正转】走到底压到 **X1**
- 轴2 无任何外部信号
- 板卡原始输入：导通读到 **1**（限位常闭 = 正常时 1，撞开 = 0 = 触发）

## 代码约定

- `Form1.Designer.cs` 放全部界面（用户要求用设计器，不要代码生成控件）
- `Form1.cs` 只放逻辑，目前约 450 行
- ~~限位常量按方向命名 `LIMIT_FWD_INDEX=1` / `LIMIT_REV_INDEX=0`~~ —— **2026-10-27 15:57 用户要求把程序里所有限位内容删掉了**
  - 已删：限位判断、方向互锁、软件轮询停车、卡内硬限位（`GA_SetHardLimP/N` + `GA_LmtsOn`）、限位状态条、原始输入 X 显示
  - 后果：**轴1 走到两端不会自动停**，全靠人看着；要恢复需要重新接回去
  - 保留：原点 Home1 检测、回零、设零点、位置 mm 换算、标定面板
- 停车一律用 `GA_Stop(mask, 0)`，**不要用 `GA_SetVel(ax, 0)`**（速度模式下不可靠）
- `Ppm()` 里 80 / 255 脉冲/mm 是**占位值，未标定**（已改成可运行时标定的字段 + `axis-cal.ini`）
- **回零方向必须按位置判断**（用户 2026-10-27 明确要求）：
  - `pos1 > 0`（原点 ↔ X1 正转端之间）→ 朝**反转端**找
  - `pos1 < 0`（原点 ↔ X0 反转端之间）→ 朝**正转端**找
  - 未知（本次连接还没回过零）→ 先猜正转端，撞到限位自动掉头重找
- 回零参数的方向取值与手册**相反**：`HomeTowardsFwd = 0`（朝 X1）、`HomeTowardsRev = 1`（朝 X0）
